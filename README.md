# Zapind Documentation Site

Official documentation and landing page for **Zapind** (`v0.1.0`) — built with VitePress.

- Vietnamese docs: `/vi/`
- English docs: `/en/`
- Light / Dark mode switcher & Local Search built in

## Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run typecheck
npm run build
npm run preview
```
